Case Study

EduPlatform — Full Stack LMS

Problem

Students need one place to access courses, tests, certificates and progress.

Solution

I built a complete LMS with student, teacher and admin dashboards.

Frontend

Responsive pages for login, register, dashboards, course purchase and test flow.

Backend

Node.js and Express.js REST APIs for auth, courses, purchases and results.

Database

MySQL tables manage users, courses, enrollments, payments and certificates.

Learning

This project improved my role-based access, API design and database skills.
